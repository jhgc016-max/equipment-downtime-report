작업일보 스캔본 읽기

생산작업일보(가공설비)와 자동용접 ROBOT 가동일보의 PDF·사진을 무료로 읽습니다. 문서는 브라우저에서 처리하며 API 키·결제가 필요 없습니다. 손글씨와 표는 잘못 인식될 수 있으므로 원본 옆에서 사람이 확인·수정한 뒤 집계로 보냅니다.

1. 스캔본을 올리세요

PDF · JPG · PNG · WEBP를 지원합니다. 파일당 최대 10MB, PDF 최대 30쪽입니다. 한 장에 일보 한 장이 들어가게 찍어 주세요.

2. 무료로 PDF · 사진 읽기

API 키와 결제가 필요 없습니다. PDF의 글자를 먼저 추출하고 스캔·사진은 한국어·영어 OCR로 읽습니다. 문서는 외부로 업로드하지 않고 이 브라우저에서 처리합니다. 처음 실행할 때 무료 PDF/OCR 프로그램과 언어 데이터를 인터넷에서 다운로드합니다. 파일당 10MB·PDF 최대 30쪽이며, 손글씨는 정확하지 않을 수 있어 반드시 원본과 대조해 주세요.

3. 읽은 값 확인 · 수정

원본과 대조하며 틀린 칸을 고치세요. 「확인할 것」이 남아 있어도 보낼 수는 있지만 집계에서 빠지거나 미분류로 셉니다.

4. 집계로 보내기

읽은 줄을 이 도구의 입력 양식(설비 · 설비군 · 작업자 · 날짜 · 근무 · 구분 · 코드 · 시작 · 종료 · 소요 · 내용)으로 바꿉니다. 양식의 범례 이름으로 집계 코드표를 다시 찾아 맞춥니다.

이번 판에서 하지 않는 것

  • 완벽한 손글씨 인식 — 무료 OCR은 손글씨와 복잡한 표를 잘못 읽거나 놓칠 수 있습니다. 원본과 비교하고 누락된 행을 직접 추가하세요.
  • 확인 없이 집계 — 무료 도구가 읽은 값은 반드시 사람이 본 뒤에 보냅니다. 읽기 확신이 낮거나 못 읽은 칸은 「확인할 것」에 올립니다.
  • 스캔본 보관 — 이 화면을 닫으면 이미지는 사라집니다(읽은 값만 집계 화면으로 넘어갑니다).
