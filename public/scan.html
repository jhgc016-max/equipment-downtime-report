작업일보 스캔본 읽기

손으로 쓴 생산작업일보(가공설비)와 자동용접 ROBOT 가동일보 스캔본(사진 · PDF)을 올리면 AI 비전이 표를 읽어 옵니다. 읽은 값은 원본 옆에서 사람이 확인 · 수정한 뒤에만 집계 입력 양식으로 넘어갑니다. 키가 없으면 같은 표를 손으로 넣습니다. 동의한 파일은 브라우저에서 OpenAI로 직접 전송됩니다. API 키는 이 화면에서만 사용하며 브라우저 저장소에 저장하지 않습니다. OpenAI 보관 정책은 조직의 API 데이터 정책을 확인하세요.

1. 스캔본을 올리세요

사진(JPG · PNG · WEBP)이 가장 잘 읽힙니다. GPT-6.1 Sol로 사진과 PDF를 읽습니다. 파일당 최대 10MB입니다. 한 장에 일보 한 장이 들어가게 찍어 주세요.

2. AI 로 읽기 (선택)

PC에서 ChatGPT로 PDF 읽기

아래 버튼으로 실행에 필요한 프로젝트 전체를 ZIP 파일로 받으세요.

PC 실행 프로그램 다운로드 (ZIP)Node.js 설치
  1. Node.js 22.12 이상이 없으면 먼저 설치하세요. 이미 설치했다면 건너뛰세요.
  2. 받은 ZIP을 우클릭해 모두 압축 풀기를 선택하세요.
  3. 풀린 equipment-downtime-report-main 폴더 안의 start-chatgpt.cmd를 더블클릭하세요. ZIP 안에서 바로 실행하지 마세요.
  4. 첫 실행은 준비 시간이 걸립니다. 자동으로 열린 화면에서 ChatGPT로 로그인한 뒤 PDF를 선택해 읽으세요.

실행 중에는 검은 창을 켜 두세요. 브라우저가 ZIP을 자동 실행하지는 않습니다. CMD 파일만 따로 받으면 실행되지 않으니 풀린 폴더 전체를 유지하세요.

ChatGPT 연결 확인 중…

구독 사용량 관리

PC의 start-chatgpt.cmd로 연 화면에서 로그인합니다. 계정별 구독 사용 권한·한도와 PDF·이미지 지원 여부에 따라 요청이 거절될 수 있습니다. 다른 모델로 자동 전환하지 않습니다.

보내기 전에 확인하세요. 올린 사진·PDF 전체가 OpenAI로 전송됩니다. 승인된 ChatGPT 구독 사용 권한과 한도가 적용됩니다. 작업자 이름 등 개인정보가 보이면 가린 뒤 올리거나, 사내 규정상 허용된 자료인지 먼저 확인해 주세요.

3. 읽은 값 확인 · 수정

원본과 대조하며 틀린 칸을 고치세요. 「확인할 것」이 남아 있어도 보낼 수는 있지만 집계에서 빠지거나 미분류로 셉니다.

4. 집계로 보내기

읽은 줄을 이 도구의 입력 양식(설비 · 설비군 · 작업자 · 날짜 · 근무 · 구분 · 코드 · 시작 · 종료 · 소요 · 내용)으로 바꿉니다. 위에서 확인·수정한 범례 코드는 그대로 전달하며, 사유 이름은 집계 설정의 코드표에서 찾습니다.

이번 판에서 하지 않는 것

  • API 키 없이 자동 인식 — 브라우저 안 OCR 은 손글씨 한글 표를 믿을 만큼 읽지 못해 넣지 않았습니다. API 키가 없으면 「손으로 입력」으로 같은 표를 채웁니다.
  • 확인 없이 집계 — AI 가 읽은 값은 반드시 사람이 본 뒤에 보냅니다. 읽기 확신이 낮거나 못 읽은 칸은 「확인할 것」에 올립니다.
  • 스캔본 보관 — 이 화면을 닫으면 이미지는 사라집니다(읽은 값만 집계 화면으로 넘어갑니다).
